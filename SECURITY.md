# Security Policy

## Supported versions

Only the latest minor release receives security fixes before 1.0, and the latest
major after it.

## Reporting a vulnerability

Please do not open a public issue. Report vulnerabilities privately through
[GitHub security advisories][advisories]. You will get an acknowledgement within
three working days.

Never include a live API key, sending key or webhook secret in a report. If one
has been exposed, revoke it from the Brudcast dashboard immediately.

[advisories]:
  https://github.com/brudcast/brudcast-sdk-node/security/advisories/new
